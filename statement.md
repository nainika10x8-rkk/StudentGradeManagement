# Project Statement

## Project Title

Student Course & Grade Management System

## Problem Statement

Managing student information, courses, marks, and academic results manually can be time-consuming and may lead to errors, duplicate records, and difficulty in generating reports.

The proposed system provides a centralized Java-based application for managing student academic records efficiently.

## Scope

The system covers:

- Student information management
- Course management
- Marks management
- Grade calculation
- Student result viewing
- Academic report generation and export

## Target Users

The primary users of the system are:

- Faculty/Admin users who manage student, course, and marks records
- Students who access their academic information through the student portal

## High-Level Features

1. Student Management
2. Course Management
3. Marks and Grade Management
4. Student Portal
5. Report Generation and Export
6. Input Validation and Exception Handling

## Technologies

- Java
- MySQL
- JDBC
- Object-Oriented Programming
- Collections
- File I/O
- Exception Handling
- Git/GitHub
