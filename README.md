# Student Course & Grade Management System

## Overview

The Student Course & Grade Management System is a Java console-based application developed for managing student information, courses, marks, grades, and academic reports.

The system uses Java, MySQL, and JDBC to provide a structured and reliable way to perform student and course management operations.

## Features

- Student Management
  - Add student
  - View students
  - Update student
  - Delete student

- Course Management
  - Add course
  - View courses
  - Update course
  - Delete course

- Marks & Result Management
  - Enter marks
  - View marks
  - Update marks
  - Delete marks
  - Automatic grade calculation
  - Marks validation from 0 to 100

- Student Portal
  - Student login
  - View profile
  - View courses
  - View marks
  - View result
  - Export result

- Reporting
  - Generate student marks report
  - Export reports to text files

## Technologies Used

- Java
- MySQL
- JDBC
- Object-Oriented Programming
- Collections
- File I/O
- Exception Handling
- Git & GitHub
